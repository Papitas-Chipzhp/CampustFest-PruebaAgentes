# CampusFest

Sistema de escritorio en Java 21 + JavaFX 21 para la gestión de cupos, reservas temporales de entradas, edición de eventos y control de ingreso mediante código QR en eventos universitarios, desarrollado bajo Arquitectura Limpia y persistencia embebida en H2.

## Requisitos y ejecución

- **Java**: JDK 21 (o superior compatible con `--release 21`)
- **Apache Maven**: 3.9+

### Comandos principales

```bash
# Ejecutar la suite completa de pruebas automatizadas
mvn test

# Iniciar la aplicación JavaFX
mvn javafx:run
```
